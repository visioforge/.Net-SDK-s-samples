# Video Edit SDK .Net - mux-streams-winforms (C#/WinForms)

El código del [tutorial para combinar fuentes de vídeo y audio](https://www.visioforge.com/help/es/docs/dotnet/videoedit/code-samples/output-file-from-multiple-sources/): una aplicación WinForms sobre `VideoEditCore` que toma la pista de vídeo de un archivo y la pista de audio de otro y las escribe en un solo archivo MP4 sin recodificar, con `FastEdit_MuxStreamsAsync`.

Elija el archivo de vídeo y el archivo de audio y pulse Start. El archivo se guarda en `Videos\output.mp4`, salvo que escriba otra ruta.

## Marcos compatibles

* .Net 10
