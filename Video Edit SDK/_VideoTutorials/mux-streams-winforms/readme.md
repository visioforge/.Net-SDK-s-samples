# Video Edit SDK .Net - mux-streams-winforms (C#/WinForms)

The code of the [merge video and audio sources tutorial](https://www.visioforge.com/help/docs/dotnet/videoedit/code-samples/output-file-from-multiple-sources/): a WinForms app on `VideoEditCore` that takes the video stream of one file and the audio stream of another and writes them into one MP4 file without re-encoding, with `FastEdit_MuxStreamsAsync`.

Pick the video file and the audio file, and press Start. The file is saved to `Videos\output.mp4` unless you type another path.

## Supported frameworks

* .Net 10
