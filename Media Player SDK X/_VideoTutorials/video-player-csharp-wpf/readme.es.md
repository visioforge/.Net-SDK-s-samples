# Media Player SDK .Net - video-player-csharp-wpf (C#/WPF)

El código del [tutorial en vídeo del reproductor de vídeo en C#](https://www.youtube.com/watch?v=YJbUV370TKo): una aplicación WPF sobre `MediaPlayerCoreX` que reproduce un archivo de vídeo con línea de tiempo, pausa y reanudación, volumen, velocidad de reproducción y elección de la salida de audio.

## Marcos compatibles

* .Net 10
