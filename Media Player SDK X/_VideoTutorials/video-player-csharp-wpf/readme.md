# Media Player SDK .Net - video-player-csharp-wpf (C#/WPF)

The code of the [video player in C# video tutorial](https://www.youtube.com/watch?v=YJbUV370TKo): a WPF app on `MediaPlayerCoreX` that plays a video file with a timeline, pause and resume, volume, playback speed and a choice of the audio output.

## Supported frameworks

* .Net 10
