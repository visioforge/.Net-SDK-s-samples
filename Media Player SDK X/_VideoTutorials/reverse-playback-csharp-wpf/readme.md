# Media Player SDK .Net - reverse-playback-csharp-wpf (C#/WPF)

The code of the [reverse playback video tutorial](https://www.youtube.com/watch?v=sL9v_lKJYyM): a WPF app on `MediaPlayerCoreX` that plays a video file backwards from the current position or from the end, changes the speed in either direction and steps one frame back.

## Supported frameworks

* .Net 10
