# Media Player SDK .Net - reverse-playback-csharp-wpf (C#/WPF)

El código del tutorial en vídeo de reproducción inversa: una aplicación WPF sobre `MediaPlayerCoreX` que reproduce un archivo de vídeo hacia atrás desde la posición actual o desde el final, cambia la velocidad en cualquier dirección y retrocede un fotograma.

## Marcos compatibles

* .Net 10
