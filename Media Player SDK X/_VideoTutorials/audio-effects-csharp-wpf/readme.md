# Media Player SDK .Net - audio-effects-csharp-wpf (C#/WPF)

The code of the audio effects video tutorial: a WPF app on `MediaPlayerCoreX` that plays a media file and changes a 10-band equalizer, echo, reverb and pitch while it plays.

## Supported frameworks

* .Net 10
