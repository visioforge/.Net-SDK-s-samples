# Media Player SDK .Net - audio-effects-csharp-wpf (C#/WPF)

El código del tutorial en vídeo de efectos de audio: una aplicación WPF sobre `MediaPlayerCoreX` que reproduce un archivo multimedia y cambia un ecualizador de 10 bandas, el eco, la reverberación y el tono durante la reproducción.

## Marcos compatibles

* .Net 10
