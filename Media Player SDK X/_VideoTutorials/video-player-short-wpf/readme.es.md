# Media Player SDK .Net - video-player-short-wpf (C#/WPF)

El código del vídeo corto "Reproducir un vídeo con unas pocas líneas de C#": una ventana WPF con un `VideoView` que reproduce `video.mp4` de su propia carpeta con `MediaPlayerCoreX`. Coloque allí su propio vídeo, con el mismo nombre, para reproducir otro archivo. El tutorial completo, con línea de tiempo, pausa y reanudación, volumen, velocidad de reproducción y elección de la salida de audio, es el [tutorial en vídeo del reproductor de vídeo en C#](https://www.youtube.com/watch?v=YJbUV370TKo).

## Marcos compatibles

* .Net 10
