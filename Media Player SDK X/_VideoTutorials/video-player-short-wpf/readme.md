# Media Player SDK .Net - video-player-short-wpf (C#/WPF)

The code of the short video "Play a Video in a Few Lines of C#": a WPF window with a `VideoView` that plays `video.mp4` from its own folder with `MediaPlayerCoreX`. Put your own video there, under the same name, to play a different file. The full walkthrough, with a timeline, pause and resume, volume, playback speed and a choice of the audio output, is the [video player in C# video tutorial](https://www.youtube.com/watch?v=YJbUV370TKo).

## Supported frameworks

* .Net 10
