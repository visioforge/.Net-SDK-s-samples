# Video Capture SDK .Net - ip-camera-capture-mp4-winforms (C#/WinForms)

El código del [tutorial en video de cámara IP a MP4](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-capture-mp4/): una aplicación WinForms sobre `VideoCaptureCoreX` que graba una cámara IP RTSP en MP4 a partir de su URL, usuario y contraseña, con vista previa en directo y el audio de la cámara, con H.264 en la GPU y alternativa en la CPU.

## Marcos compatibles

* .Net 10
