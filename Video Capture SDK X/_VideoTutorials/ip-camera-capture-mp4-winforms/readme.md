# Video Capture SDK .Net - ip-camera-capture-mp4-winforms (C#/WinForms)

The code of the [IP camera to MP4 video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-capture-mp4/): a WinForms app on `VideoCaptureCoreX` that records an RTSP IP camera to MP4 from its URL, login and password, with a live preview and the camera's audio, with H.264 on the GPU and a CPU fallback.

## Supported frameworks

* .Net 10
