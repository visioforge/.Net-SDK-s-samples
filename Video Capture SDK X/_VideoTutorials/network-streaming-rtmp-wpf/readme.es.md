# Video Capture SDK .Net - network-streaming-rtmp-wpf (C#/WPF)

El código del [tutorial en vídeo de streaming de webcam en red](https://www.youtube.com/watch?v=epXiu2VhuzQ): una aplicación WPF sobre `VideoCaptureCoreX` que muestra la vista previa de una webcam y la transmite con el micrófono por RTMP, en H.264 y AAC, a un servidor de medios como MediaMTX, YouTube Live o cualquier punto de ingesta RTMP.

## Marcos compatibles

* .Net 10
