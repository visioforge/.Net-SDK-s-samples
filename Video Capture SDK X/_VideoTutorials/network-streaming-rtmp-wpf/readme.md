# Video Capture SDK .Net - network-streaming-rtmp-wpf (C#/WPF)

The code of the [webcam network streaming video tutorial](https://www.youtube.com/watch?v=epXiu2VhuzQ): a WPF app on `VideoCaptureCoreX` that previews a webcam and streams it with the microphone over RTMP, H.264 and AAC, to a media server such as MediaMTX, YouTube Live or any RTMP ingest.

## Supported frameworks

* .Net 10
