# Video Capture SDK .Net - webcam-mp4-short-console (C#/Console)

El código del vídeo corto «Grabar una webcam en MP4 con unas pocas líneas de C#»: una aplicación de consola que graba el primer dispositivo de captura de vídeo en `webcam.mp4` hasta que se pulsa Intro. Conecte la cámara antes de iniciar la aplicación; para usar otra cámara, elíjala por su nombre en la lista de dispositivos de `Program.cs`. Detenga la grabación con Intro: cerrar la ventana o pulsar Ctrl+C termina la aplicación sin `StopAsync`, y el archivo MP4 queda sin terminar. El recorrido completo, con vista previa en directo, el sonido de la cámara y una interfaz WinForms, es el [tutorial en vídeo de webcam a MP4](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/video-capture-webcam-mp4/).

## Marcos compatibles

* .Net 10
