# Video Capture SDK .Net - webcam-mp4-short-console (C#/Console)

The code of the short video "Record Your Webcam to MP4 in a Few Lines of C#": a console app that records the first video capture device to `webcam.mp4` until Enter is pressed. Plug the camera in before the app starts; to use a different camera, pick it by name from the device list in `Program.cs`. Stop with Enter: closing the window or Ctrl+C ends the app without `StopAsync`, and the MP4 file is left unfinished. The full walkthrough, with a live preview, the camera's sound and a WinForms UI, is the [webcam to MP4 video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/video-capture-webcam-mp4/).

## Supported frameworks

* .Net 10
