# Video Capture SDK .Net - ip-camera-mp4-short-console (C#/Console)

El código del vídeo corto «Grabar una cámara IP en MP4 con unas pocas líneas de C#»: una aplicación de consola que graba una cámara IP RTSP en `ipcam.mp4` hasta que se pulsa Intro. Pase la URL de la cámara como primer argumento y ponga el usuario y la contraseña de la cámara en lugar de `admin` y `password` en `Program.cs`. Detenga la grabación con Intro: cerrar la ventana o pulsar Ctrl+C termina la aplicación sin `StopAsync`, y el archivo MP4 queda sin terminar. El recorrido completo, con vista previa en directo, el sonido de la cámara y una interfaz WinForms, es el [tutorial en vídeo de cámara IP a MP4](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-capture-mp4/).

## Marcos compatibles
