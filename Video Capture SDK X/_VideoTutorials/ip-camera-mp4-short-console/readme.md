# Video Capture SDK .Net - ip-camera-mp4-short-console (C#/Console)

The code of the short video "Record an IP Camera to MP4 in a Few Lines of C#": a console app that records an RTSP IP camera to `ipcam.mp4` until Enter is pressed. Pass the camera URL as the first argument, and put the camera's login and password in place of `admin` and `password` in `Program.cs`. Stop with Enter: closing the window or Ctrl+C ends the app without `StopAsync`, and the MP4 file is left unfinished. The full walkthrough, with a live preview, the camera's sound and a WinForms UI, is the [IP camera to MP4 video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-capture-mp4/).

## Supported frameworks

* .Net 10
