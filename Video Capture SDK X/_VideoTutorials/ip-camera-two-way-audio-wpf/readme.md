# Video Capture SDK .Net - ip-camera-two-way-audio-wpf (C#/WPF)

The code of the [IP camera two-way audio tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-two-way-audio/): a WPF app on `VideoCaptureCoreX` that shows an RTSP IP camera with its own sound and sends the PC microphone to the camera speaker over the ONVIF audio backchannel, like an intercom or a video doorbell.

## Supported frameworks

* .Net 10
