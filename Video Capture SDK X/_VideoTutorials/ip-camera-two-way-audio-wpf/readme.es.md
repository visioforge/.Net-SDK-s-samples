# Video Capture SDK .Net - ip-camera-two-way-audio-wpf (C#/WPF)

El código del [tutorial de audio bidireccional con cámaras IP](https://www.visioforge.com/help/es/docs/dotnet/videocapture/video-tutorials/ip-camera-two-way-audio/): una aplicación WPF sobre `VideoCaptureCoreX` que muestra una cámara IP RTSP con su propio sonido y envía el micrófono del PC al altavoz de la cámara por el backchannel de audio ONVIF, como un intercomunicador o un videoportero.

## Marcos compatibles

* .Net 10
