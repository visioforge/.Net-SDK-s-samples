# Video Capture SDK .Net - screen-mp4-short-console (C#/Console)

The code of the short video "Record Your Screen to MP4 in a Few Lines of C#": a console app that records the whole primary screen, with the mouse cursor, at 30 frames per second to `screen.mp4` until Enter is pressed. Stop with Enter: closing the window or Ctrl+C ends the app without `StopAsync`, and the MP4 file is left unfinished. The full walkthrough, with the system sound, a live preview and a WPF UI, is the [screen capture to MP4 video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/screen-capture-mp4/).

## Supported frameworks

* .Net 10
