# Video Capture SDK .Net - screen-mp4-short-console (C#/Console)

El código del vídeo corto «Grabar la pantalla en MP4 con unas pocas líneas de C#»: una aplicación de consola que graba toda la pantalla principal, con el cursor del ratón, a 30 fotogramas por segundo en `screen.mp4` hasta que se pulsa Intro. Detenga la grabación con Intro: cerrar la ventana o pulsar Ctrl+C termina la aplicación sin `StopAsync`, y el archivo MP4 queda sin terminar. El recorrido completo, con el sonido del sistema, vista previa en directo y una interfaz WPF, es el [tutorial en vídeo de captura de pantalla a MP4](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/screen-capture-mp4/).

## Marcos compatibles

* .Net 10
