# Video Capture SDK .Net - screen-capture-mp4-wpf (C#/WPF)

El código del [tutorial en vídeo de captura de pantalla a MP4](https://www.youtube.com/watch?v=17eaRlDqM_I): una aplicación WPF sobre `VideoCaptureCoreX` que graba la pantalla y el sonido del sistema en MP4 con vista previa en directo, con H.264 en la GPU y alternativa en la CPU.

## Marcos compatibles

* .Net 10
