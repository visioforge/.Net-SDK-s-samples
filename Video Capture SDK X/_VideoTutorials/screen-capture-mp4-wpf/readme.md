# Video Capture SDK .Net - screen-capture-mp4-wpf (C#/WPF)

The code of the [screen capture to MP4 video tutorial](https://www.youtube.com/watch?v=17eaRlDqM_I): a WPF app on `VideoCaptureCoreX` that records the screen and the system sound to MP4 with a live preview, with H.264 on the GPU and a CPU fallback.

## Supported frameworks

* .Net 10
