# Media Player SDK .Net - memory-playback-wpf (C#/WPF)

The code of the [play a video from memory video tutorial](https://www.youtube.com/watch?v=zSu_50b7IVQ): a WPF app that plays a video file from a .NET stream instead of a file name, either a `FileStream` or the whole file read into a byte array and wrapped in a `MemoryStream`, with pause, resume, stop and a timeline.

## Supported frameworks

* .Net 10
