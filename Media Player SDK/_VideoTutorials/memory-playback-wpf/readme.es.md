# Media Player SDK .Net - memory-playback-wpf (C#/WPF)

El código del [tutorial en vídeo de reproducción de vídeo desde memoria](https://www.youtube.com/@VisioForgeTutorials): una aplicación WPF que reproduce un archivo de vídeo desde un flujo de .NET en lugar de un nombre de archivo, ya sea un `FileStream` o el archivo completo leído en una matriz de bytes y envuelto en un `MemoryStream`, con pausa, reanudación, detención y línea de tiempo.

## Marcos compatibles

* .Net 10
