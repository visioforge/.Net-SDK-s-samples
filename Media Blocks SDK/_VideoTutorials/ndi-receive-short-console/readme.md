# Media Blocks SDK .Net - ndi-receive-short-console (C#/Console)

The receive half of the short video "Send and Receive NDI Video in a Few Lines of C#": a console app that connects to an NDI source by name, shows its video in a window of its own and plays its audio, when the source has audio, until Enter is pressed. Pass the source name as the first argument, as NDI lists it: the computer name, then the source name in parentheses, for example `"WIN11 (VisioForge NDI)"`. The NDI runtime (NDI Tools) must be installed. The send half is `ndi-send-short-console`. The full walkthrough, with a list of the sources on the network and a WPF UI that also sends, is the [NDI send and receive video tutorial](https://www.youtube.com/watch?v=_9aDu_hk2uw).

## Supported frameworks

* .Net 10
