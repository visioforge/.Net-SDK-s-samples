# Media Blocks SDK .Net - ndi-send-short-console (C#/Console)

La mitad de envío del vídeo corto "Send and Receive NDI Video in a Few Lines of C#": una aplicación de consola que emite un archivo de vídeo por NDI, con su vídeo, y su audio si el archivo tiene pista de audio, como la fuente `VisioForge NDI` hasta que se pulsa Enter. Pase la ruta del archivo como primer argumento. Requiere el runtime de NDI (NDI Tools) instalado. La mitad de recepción es `ndi-receive-short-console`. La explicación completa, con una webcam, vista previa en directo y una interfaz WPF que también recibe, es el [tutorial en vídeo de envío y recepción por NDI](https://www.youtube.com/watch?v=_9aDu_hk2uw).

## Marcos compatibles

* .Net 10
