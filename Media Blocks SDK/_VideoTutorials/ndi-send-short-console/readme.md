# Media Blocks SDK .Net - ndi-send-short-console (C#/Console)

The send half of the short video "Send and Receive NDI Video in a Few Lines of C#": a console app that plays a video file out over NDI, its video, and its audio when the file has an audio track, as the source `VisioForge NDI` until Enter is pressed. Pass the file path as the first argument. The NDI runtime (NDI Tools) must be installed. The receive half is `ndi-receive-short-console`. The full walkthrough, with a webcam, a live preview and a WPF UI that also receives, is the [NDI send and receive video tutorial](https://www.youtube.com/watch?v=_9aDu_hk2uw).

## Supported frameworks

* .Net 10
