# Media Blocks SDK .Net - ndi-send-receive-wpf (C#/WPF)

The code of the NDI send and receive video tutorial: a WPF app on `MediaBlocksPipeline` that sends a webcam and its microphone over NDI with `NDISinkBlock`, lists the NDI senders on the network and plays the chosen one, video and audio, with `NDISourceBlock`. The NDI runtime (NDI Tools) must be installed.

## Supported frameworks

* .Net 10
