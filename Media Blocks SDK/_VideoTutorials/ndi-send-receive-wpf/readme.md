# Media Blocks SDK .Net - ndi-send-receive-wpf (C#/WPF)

The code of the [NDI send and receive video tutorial](https://www.youtube.com/watch?v=_9aDu_hk2uw): a WPF app on `MediaBlocksPipeline` that sends a webcam and its microphone over NDI with `NDISinkBlock`, lists the NDI senders on the network and plays the chosen one with `NDISourceBlock` - its video, and its audio when Play audio is ticked. The NDI runtime (NDI Tools) must be installed.

## Supported frameworks

* .Net 10
