# Media Blocks SDK .Net - ndi-send-receive-wpf (C#/WPF)

El código del [tutorial en vídeo de envío y recepción por NDI](https://www.youtube.com/watch?v=_9aDu_hk2uw): una aplicación WPF sobre `MediaBlocksPipeline` que envía una webcam y su micrófono por NDI con `NDISinkBlock`, enumera los emisores NDI de la red y reproduce el elegido con `NDISourceBlock`: su vídeo, y su audio cuando Play audio está marcado. Requiere el runtime de NDI (NDI Tools) instalado.

## Marcos compatibles

* .Net 10
