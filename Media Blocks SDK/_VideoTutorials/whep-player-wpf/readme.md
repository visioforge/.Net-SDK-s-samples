# Media Blocks SDK .Net - whep-player-wpf (C#/WPF)

The code of the WebRTC playback over WHEP video tutorial: a WPF app on `MediaBlocksPipeline` that plays a WebRTC stream from any WHEP URL (MediaMTX, Janus, Cloudflare Stream) with `WHEPSourceBlock` - its video, and its audio when Audio is ticked - with the renderers' `IsSync` off for the lowest latency. Step by step: [Play a WebRTC Stream over WHEP in C# WPF](https://www.visioforge.com/help/docs/dotnet/mediablocks/Guides/webrtc-whep-player/).

## Supported frameworks

* .Net 10
