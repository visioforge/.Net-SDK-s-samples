# Media Blocks SDK .Net - whep-player-wpf (C#/WPF)

El código del tutorial en vídeo de reproducción WebRTC por WHEP: una aplicación WPF sobre `MediaBlocksPipeline` que reproduce un stream WebRTC desde cualquier URL WHEP (MediaMTX, Janus, Cloudflare Stream) con `WHEPSourceBlock`: su vídeo, y su audio cuando Audio está marcado, con `IsSync` desactivado en los renderizadores para la latencia más baja. Paso a paso: [Reproducir WebRTC por WHEP en C# WPF](https://www.visioforge.com/help/es/docs/dotnet/mediablocks/Guides/webrtc-whep-player/).

## Marcos compatibles

* .Net 10
