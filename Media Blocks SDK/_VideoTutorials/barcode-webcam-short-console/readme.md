# Media Blocks SDK .Net - barcode-webcam-short-console (C#/Console)

The sample of the short video "Webcam QR Code & Barcode Scanner in a Few Lines of C#": a console app that reads QR codes and barcodes from the first webcam and prints each new code once, with its type, until Enter is pressed. `BarcodeDetectorBlock` reads QR codes and the common 1D barcodes, such as EAN-13, UPC-A and Code 128. The camera is the first video capture device the system lists; pick another one from `DeviceEnumerator.Shared.VideoSourcesAsync()` by its name. The [barcode and QR code reader guide](https://www.visioforge.com/help/docs/dotnet/mediablocks/Guides/barcode-qr-reader-guide/) adds a live preview and other sources.

## Supported frameworks

* .Net 10
