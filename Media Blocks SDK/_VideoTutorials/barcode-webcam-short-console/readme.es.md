# Media Blocks SDK .Net - barcode-webcam-short-console (C#/Console)

El ejemplo del vídeo corto "Webcam QR Code & Barcode Scanner in a Few Lines of C#": una aplicación de consola que lee códigos QR y códigos de barras desde la primera webcam e imprime cada código nuevo una sola vez, con su tipo, hasta que se pulsa Enter. `BarcodeDetectorBlock` lee códigos QR y los códigos de barras 1D habituales, como EAN-13, UPC-A y Code 128. La cámara es el primer dispositivo de captura de vídeo que lista el sistema; para usar otra, elíjala por su nombre en `DeviceEnumerator.Shared.VideoSourcesAsync()`. La [guía del lector de códigos de barras y QR](https://www.visioforge.com/help/es/docs/dotnet/mediablocks/Guides/barcode-qr-reader-guide/) añade una vista previa en vivo y otras fuentes.

## Marcos compatibles

* .Net 10
