# Media Blocks SDK .Net - webrtc-browser-short-console (C#/Console)

The sample of the video short "Stream a Camera to a Browser in a Few Lines of C#": a console app that sends the first camera to web browsers over WebRTC, with no media server. `WebRTCSinkBlock` serves the viewer page from `wwwroot` and runs the signalling itself. Run it, open `http://localhost:8090/?signalling=8443` in a browser, and press Enter in the console to stop. The [guide](https://www.visioforge.com/help/docs/dotnet/mediablocks/Guides/webrtc-whip/) covers a screen or a window as the source, viewers on other computers, and WHIP publishing to a media server.

## Supported frameworks

* .Net 10
