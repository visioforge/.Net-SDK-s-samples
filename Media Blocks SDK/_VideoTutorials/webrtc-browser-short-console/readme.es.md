# Media Blocks SDK .Net - webrtc-browser-short-console (C#/Console)

El ejemplo del vídeo corto "Stream a Camera to a Browser in a Few Lines of C#": una aplicación de consola que envía la primera cámara a navegadores web por WebRTC, sin servidor de medios. `WebRTCSinkBlock` sirve la página del espectador desde `wwwroot` y ejecuta la señalización por sí mismo. Ejecútela, abra `http://localhost:8090/?signalling=8443` en un navegador y pulse Enter en la consola para detenerla. La [guía](https://www.visioforge.com/help/es/docs/dotnet/mediablocks/Guides/webrtc-whip/) trata la pantalla o una ventana como fuente, los espectadores en otros equipos y la publicación WHIP en un servidor de medios.

## Frameworks compatibles

* .Net 10
