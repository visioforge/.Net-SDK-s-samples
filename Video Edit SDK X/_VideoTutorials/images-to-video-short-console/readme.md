# Video Edit SDK .Net - images-to-video-short-console (C#/Console)

The code of the short video "Make a Video from Photos in a Few Lines of C#": a console app on `VideoEditCoreX` that turns a folder of `.jpg` images into an MP4 slideshow, with a crossfade between the images and a fade in and out. The full walkthrough, with the wipes, the timing and the common mistakes, is the [video from images tutorial](https://www.youtube.com/watch?v=Kef_q2cvdAI).

Run it with the image folder and the output file as the arguments: `images-to-video-short-console Pictures\slides slideshow.mp4`.

## Supported frameworks

* .Net 10
