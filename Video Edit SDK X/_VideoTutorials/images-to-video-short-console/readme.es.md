# Video Edit SDK .Net - images-to-video-short-console (C#/Console)

El código del vídeo corto "Crear un vídeo a partir de fotos con unas pocas líneas de C#": una aplicación de consola sobre `VideoEditCoreX` que convierte una carpeta de imágenes `.jpg` en una presentación MP4, con un fundido encadenado entre las imágenes y un fundido de entrada y de salida. El tutorial completo, con las cortinillas, los tiempos y los errores frecuentes, es el [tutorial de vídeo a partir de imágenes](https://www.youtube.com/watch?v=Kef_q2cvdAI).

Ejecútela con la carpeta de imágenes y el archivo de salida como argumentos: `images-to-video-short-console Pictures\slides slideshow.mp4`.

## Marcos compatibles

* .Net 10
