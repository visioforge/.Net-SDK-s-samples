# Video Edit SDK .Net - images-to-video-console (C#/Console)

El código del [tutorial de vídeo a partir de imágenes](https://www.visioforge.com/help/docs/dotnet/videoedit/code-samples/video-images-console/): una aplicación de consola sobre `VideoEditCoreX` que convierte una carpeta de imágenes JPEG en una presentación MP4, con un fundido encadenado, cortinillas y un fundido de entrada y de salida entre las imágenes.

Ejecútela con la carpeta de imágenes como argumento, o coloque las imágenes en `Pictures\slides`. El vídeo se guarda en `Videos\slideshow.mp4`.

## Marcos compatibles

* .Net 10
