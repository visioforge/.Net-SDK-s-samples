# Video Edit SDK .Net - images-to-video-console (C#/Console)

The code of the [video from images tutorial](https://www.visioforge.com/help/docs/dotnet/videoedit/code-samples/video-images-console/): a console app on `VideoEditCoreX` that turns a folder of `.jpg` images into an MP4 slideshow, with a crossfade, wipes and a fade in and out between the images.

Run it with the image folder as the argument, or put the images in `Pictures\slides`. The video is saved to `Videos\slideshow.mp4`.

## Supported frameworks

* .Net 10
