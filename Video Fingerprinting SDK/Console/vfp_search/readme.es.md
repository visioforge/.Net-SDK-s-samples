# Video Fingerprinting SDK .Net - vfp_search (C#/Console)

Esta aplicación genera y analiza huellas digitales de video.

## Frameworks soportados

* .Net 10 (Windows, macOS)
* .Net 8 (Linux) - requiere los paquetes de GStreamer del sistema, consulte la [guía de implementación en Ubuntu](https://www.visioforge.com/help/es/docs/dotnet/deployment-x/Ubuntu/)
