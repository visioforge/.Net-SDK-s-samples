# Video Capture SDK .Net - screen-capture-wmv-winforms (C#/WinForms)

The code of the [screen capture to WMV video tutorial](https://www.youtube.com/watch?v=gpaVniBKXBw): a WinForms app with a live preview that records a whole monitor to WMV at the frame rate picked from a list, with or without the mouse cursor and the sound that plays on the speakers (or a microphone), encoded at a constant bitrate with the Windows Media video codec, audio codec and audio format picked from the lists Windows reports.

## Supported frameworks

* .Net 10
