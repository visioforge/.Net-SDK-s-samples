# Video Capture SDK .Net - screen-capture-wmv-winforms (C#/WinForms)

El código del [tutorial en vídeo de captura de pantalla a WMV](https://www.youtube.com/watch?v=gpaVniBKXBw): una aplicación WinForms con vista previa en directo que graba un monitor completo en WMV con la velocidad de fotogramas elegida en una lista, con o sin el cursor del ratón y el sonido que se reproduce en los altavoces (o un micrófono), codificado a velocidad de bits constante con el códec de vídeo, el códec de audio y el formato de audio de Windows Media elegidos en las listas que ofrece Windows.

## Marcos compatibles

* .Net 10
