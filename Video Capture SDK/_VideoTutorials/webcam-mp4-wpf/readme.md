# Video Capture SDK .Net - webcam-mp4-wpf (C#/WPF)

The code of the [webcam to MP4 in WPF video tutorial](https://www.youtube.com/@VisioForgeTutorials): a WPF app, its window laid out in XAML, with a live preview that records a webcam and a microphone to MP4, with H.264 on the GPU and a CPU fallback.

## Supported frameworks

* .Net 10
