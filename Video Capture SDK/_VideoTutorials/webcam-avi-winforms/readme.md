# Video Capture SDK .Net - webcam-avi-winforms (C#/WinForms)

The code of the [webcam to AVI video tutorial](https://www.youtube.com/@VisioForgeTutorials): a WinForms app with a live preview that records a webcam, and a microphone when there is one, to AVI, with the video codec picked from the ones installed on the PC (MJPEG by default) and PCM or MP3 audio.

## Supported frameworks

* .Net 10
