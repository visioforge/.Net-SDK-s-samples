# Video Capture SDK .Net - webcam-text-overlay-winforms (C#/WinForms)

El código del [tutorial en vídeo de texto superpuesto en la webcam](https://www.youtube.com/watch?v=wgRV_RT-txg): una aplicación WinForms con vista previa en directo que graba una webcam, y un micrófono si lo hay, en MP4 con texto dibujado sobre el vídeo: un rótulo que se puede cambiar durante la grabación, la fecha y la hora, el número de fotograma y el tiempo desde el inicio de la grabación.

## Marcos compatibles

* .Net 10
