# Video Capture SDK .Net - webcam-text-overlay-winforms (C#/WinForms)

The code of the [webcam text overlay video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/webcam-capture-text-overlay/): a WinForms app with a live preview that records a webcam, and a microphone when there is one, to MP4 with text drawn over the video: a caption you can change while recording, the date and time, the frame number and the time since the recording started.

## Supported frameworks

* .Net 10
