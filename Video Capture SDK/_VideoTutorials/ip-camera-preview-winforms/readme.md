# Video Capture SDK .Net - ip-camera-preview-winforms (C#/WinForms)

The code of the [IP camera preview video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-preview/): a WinForms app that shows the live preview of an RTSP IP camera from its URL, login and password, and can pixelate the picture with the Mosaic video effect.

## Supported frameworks

* .Net 10
