# Video Capture SDK .Net - ip-camera-preview-winforms (C#/WinForms)

El código del [tutorial en vídeo de vista previa de cámara IP](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/ip-camera-preview/): una aplicación WinForms que muestra la vista previa en directo de una cámara IP RTSP a partir de su URL, usuario y contraseña, y puede pixelar la imagen con el efecto de vídeo Mosaic.

## Marcos compatibles

* .Net 10
