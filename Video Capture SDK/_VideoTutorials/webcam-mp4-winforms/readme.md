# Video Capture SDK .Net - webcam-mp4-winforms (C#/WinForms)

The code of the [webcam to MP4 video tutorial](https://www.youtube.com/@VisioForgeTutorials): a WinForms app with a live preview that records a webcam and a microphone to MP4, with H.264 on the GPU and a CPU fallback.

## Supported frameworks

* .Net 10
