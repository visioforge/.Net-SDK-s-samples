# Video Capture SDK .Net - webcam-wmv-winforms (C#/WinForms)

El código del [tutorial en vídeo de webcam a WMV](https://www.youtube.com/@VisioForgeTutorials): una aplicación WinForms con vista previa en directo que graba una webcam, y un micrófono si lo hay, en un archivo WMV con la resolución de la cámara, con los códecs de vídeo y audio de Windows Media y el formato de audio elegidos en las listas que el SDK lee de Windows (Windows Media Video 9 a 8 Mbps y Windows Media Audio 9.2 a 128 kbps, 48 kHz estéreo por defecto).

## Marcos compatibles

* .Net 10
