# Video Capture SDK .Net - webcam-wmv-winforms (C#/WinForms)

The code of the [webcam to WMV video tutorial](https://www.youtube.com/@VisioForgeTutorials): a WinForms app with a live preview that records a webcam, and a microphone when there is one, to a WMV file at the camera's resolution, with the Windows Media video and audio codecs and the audio format picked from the lists the SDK reads from Windows (Windows Media Video 9 at 8 Mbps and Windows Media Audio 9.2 at 128 kbps, 48 kHz stereo by default).

## Supported frameworks

* .Net 10
