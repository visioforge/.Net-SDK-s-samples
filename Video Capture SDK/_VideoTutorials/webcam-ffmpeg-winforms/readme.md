# Video Capture SDK .Net - webcam-ffmpeg-winforms (C#/WinForms)

The code of the [webcam to MP4 and WebM through FFmpeg video tutorial](https://www.youtube.com/watch?v=bNn7p2H6i3M): a WinForms app with a live preview that records a webcam, and a microphone when there is one, at the camera's resolution through FFmpeg.exe (`FFMPEGEXEOutput`): MP4 with H.264 at 8 Mbps and AAC, WebM with VP9 at 8 Mbps and Opus, and MP4 with HEVC when the PC has an Intel, NVIDIA or AMD hardware HEVC encoder. Requires the Premium edition (it runs in trial mode for 30 days).

## Supported frameworks

* .Net 10
