# Video Capture SDK .Net - camera-video-preview-winforms (C#/WinForms)

The code of the [webcam preview with frame capture video tutorial](https://www.visioforge.com/help/docs/dotnet/videocapture/video-tutorials/camera-video-preview/): a WinForms app that shows a live webcam preview in the format and frame rate you pick, and saves the current frame to a JPEG file in Pictures, then opens it in the default image viewer.

## Supported frameworks

* .Net 10
