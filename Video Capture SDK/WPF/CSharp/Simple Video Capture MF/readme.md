# Video Capture SDK .Net — Simple Video Capture, Media Foundation (C#/WPF)

Preview or record a camera through Media Foundation. The device list is `VideoCaptureCore.Video_MediaFoundationCaptureDevices`: each entry is a size and frame rate the camera itself reports. Sizes that exist only in the DirectShow device list are not shown.

Audio, crossbar and tuner are not part of this sample. The picture in the graph is RGB24.

## Supported frameworks

* .NET 10 (Windows)
