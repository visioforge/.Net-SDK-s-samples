# Video Capture SDK .Net - Service

Esta aplicación demuestra las capacidades del SDK.

## Frameworks soportados

* .Net 4.7.2
* .Net Core 3.1
* .Net 5
* .Net 6
* .Net 7
* .Net 8
* .Net 9
* .Net 10

## Instalación

Compile el proyecto y ejecute `install.bat` como administrador. Registra el servicio **VFVidCapNetSrv** con `sc.exe`; ejecute `uninstall.bat` como administrador para eliminarlo. Compile el proyecto helper de la carpeta `..\Helper` y copie el contenido de su carpeta de compilación (`bin\<Debug|Release>\<framework>`) en la carpeta del ejecutable del servicio - el exe del helper por sí solo no arranca.
